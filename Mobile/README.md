# PassBy

Окремий React-проєкт PassBy. Вебверсія та Android-застосунок використовують один React-інтерфейс; Android запускає його через Capacitor.

## Запуск вебверсії

```sh
npm install
npm run dev
```

Мобільна вебверсія заповнює ширину й висоту екрана. Для запуску без адресного рядка встановіть опублікований сайт із HTTPS через меню браузера «Додати на головний екран» або «Встановити застосунок». Режим `standalone` задано у `public/manifest.webmanifest`.

## Android

Відкрийте папку `pssby/android` в Android Studio. Після змін у вебкоді оновіть Android-застосунок:

```sh
npm run android:sync
```

Або відкрийте Android-проєкт командою `npm run android:open`.

## Демонстраційні сценарії

- Код підтвердження телефону: `8420`.
- Для завершення вручення посилки введіть код отримувача `8420`.
- Документ, платіж, узгодження, оплата та переказ коштів симульовані. Сервер, банківський провайдер і зчитування камери ще не підключені.
- Облікові записи та кроки профілю зберігаються локально у браузері.
