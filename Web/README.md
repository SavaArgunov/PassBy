# PassBy Web (тестовий фронтенд)

React + Vite. Екрани за макетами: реєстрація/вхід, підтвердження номера, вибір ролі, верифікація картки, плюс тестова панель для перевірки API ролей.

## Запуск

```bash
cd Web
npm install
npm run dev        # http://localhost:5173
```

Бекенд має працювати на `http://localhost:8080` (наприклад, `docker compose -f docker-compose.dev.yml up`).
Запити на `/api` проксуються на бекенд, тому CORS не потрібен. Інший бекенд:

```bash
VITE_PROXY_TARGET=http://host:port npm run dev
```

## Що працює з бекендом

| Екран | API |
|---|---|
| Реєстрація | `POST /api/auth/register` (поле «Ім'я та прізвище» поки не надсилається: на бекенді його немає) |
| Вхід | `POST /api/auth/login` |
| Вибір ролі | `POST /api/roles/acquire` (`DeliveryRequester` / `Deliverer`) |
| Тестова панель | `GET /api/roles/my`, `GET /api/roles/check/*` |

## Демо-заглушки (без бекенду)

- Підтвердження номера: підійде будь-який код із 4 цифр.
- Верифікація картки: дані нікуди не надсилаються.
- Вхід через Google та «Забули пароль?»: неактивні.
- Вихід із акаунта лише очищає токен у браузері (на бекенді немає logout).

Токен зберігається в `sessionStorage`. Для продакшену це потрібно переробити.
